## 核心框架

### 第一步：需求挖掘（1分钟）

```python
# 执行此脚本：skills/autonomous-earning-system/scripts/demand_miner.py
"""
用 Brave Search 挖掘真实赚钱需求
"""
```

**需求判断标准（必须全部满足）：**
- ✅ 有真实的人在问（搜索量 > 100/月）
- ✅ 愿意付费解决（竞品存在且收费）
- ✅ 我能比现有方案好10%（差异化切入点）
- ✅ 可以自动化交付（边际成本为零）

**需求分级：**
| 级别 | 特征 | 举例 | 变现速度 |
|------|------|------|---------|
| A级 | 强刚需+高频+付费意愿高 | AI写作助手、代码生成 | 1-2周 |
| B级 | 刚需+中频 | SEO工具、数据分析 | 1个月 |
| C级 | 弱需求+长周期 | 兴趣社区、素材站 | 3个月+ |

### 第三步：竞品分析（执行脚本）

```bash
# 脚本：skills/autonomous-earning-system/scripts/competitor_radar.py
python competitor_radar.py --keyword "AI写作工具"
# 输出：TOP10竞品分析表（含月访问量、变现模式、价格、优劣势）
```

**竞品分析维度：**
- 月访问量（SimilarWeb估算）
- 变现模式（订阅？免费？联盟？）
- 价格策略（有无免费版？升级点在哪？）
- SEO排名（核心关键词排名）
- 社交媒体声量
- 用户评价（AppSumo/ProductHunt/知乎）
- 差异化切入点

输出：

```markdown
## AI工具导航站 — 变现方案

### 需求验证：✅ A级
- 每月有3000+人搜索"AI工具导航"
- 竞品存在（tools.cn/ai-bot.com）但体验差
- 你有差异化：精选+真实评测+联盟佣金

### 变现模式：联盟营销为主
- 工具推荐佣金：10-50%（AI工具普遍高返佣）
- 典型案例：Notion联盟、Canva联盟
- 预估月入：1000UV × 3%转化 × ¥30佣金 = ¥900/天

### MVP（1周上线）
1. 精选50个AI工具（人工审核质量）
2. 每个工具带真实使用评测（差异化）
3. 联盟链接嵌入（核心变现）
4. 工具分类浏览（SEO流量入口）

### 启动7天计划
Day1: 选品50个 + 注册联盟计划
Day2: 建站 + 基础SEO
Day3-4: 写50个工具描述
Day5: 接入百度统计 + Google Search Console
Day6: 提交sitemap + 社交媒体首发
Day7: 分析数据 + 优化

### 风险提示
⚠️ SEO周期长（3-6个月见效）
⚠️ 需要持续更新（每周+5工具）
✅ 建议同时做知乎/公众号引流
```

## 注意事项

- **永远先验证再投入**：小范围测试MVP后再决定是否放大
- **边际成本思维**：优先选择可复制、自动化交付的模式
- **数据驱动**：每个决策都要有数据支撑
- **快速迭代**：不要追求完美，先上线再优化
